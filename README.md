# Awesome Micro Theory

[Open the Atlas](https://xianwen-yu.github.io/awesome-micro-theory/) · [How to use the site](https://xianwen-yu.github.io/awesome-micro-theory/help/?lang=en) · [中文说明](README.zh-CN.md)

Follow a question through the papers that shaped microeconomic theory. The Atlas places original papers side by side and explains what changed in a model's assumptions, mechanism or results. The public website also includes reading guides and recent research.

## Try one comparison

Start with Kamenica and Gentzkow's *Bayesian Persuasion* (2011), then read Gentzkow and Kamenica's *Competition in Persuasion* (2017). One sender's choice of an experiment becomes a game between information providers. Open the **Successors** on a paper card to keep following the question. Each annotated connection links to its source. [Original paper](https://doi.org/10.1257/aer.101.6.2590) · [Follow-up](https://doi.org/10.1093/restud/rdw052)

| Section | What you can do |
| --- | --- |
| Atlas | Search for an author or paper, open a branch, compare assumptions and conclusions, or explore the citation map. |
| Reading Guides | Find a textbook, survey or set of lecture notes. Filter for materials available without registration. |
| Recent Papers | Follow publications, public R&Rs, US job market papers, conferences and working papers. Open a record for its evidence. |

The homepage links to a bilingual walkthrough. Papers in the citation map and papers with an editorial reading note are counted separately. R&Rs rely on author disclosures. The coverage page records the scope checked for each source.

## The website on GitHub Pages

The **github-pages** deployment in the repository sidebar gives the public website address. Visitors can read and search without a GitHub account. For deployment, local preview and the daily snapshot workflow, see [Publishing the site](PUBLISH.md).

GitHub Pages serves the reader interface and its data from the same host. The daily workflow reads public catalogue and Atlas snapshots from the existing maintenance service. Static snapshots keep the published edition readable between refreshes. Publication requires a successful build and verification.

## Corrections

Open an issue with the paper or site entry, a DOI or public author page, and the proposed change. For an annotated relationship, specify which assumption or result changed. Email the maintainer directly for privacy concerns or link removal. Full texts are linked at the source and retain their original access and reuse terms.
