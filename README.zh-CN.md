# Awesome Micro Theory

[进入研究图谱](https://xianwen-yu.github.io/awesome-micro-theory/?lang=zh) · [使用说明](https://xianwen-yu.github.io/awesome-micro-theory/help/?lang=zh) · [English](README.md)

读完一篇微观理论论文，下一篇读什么？本站把论文放回它们讨论的经济问题里。你可以对照两篇原作，看后作具体改动了哪个假设、哪条机制或哪个结论。

## 第一次访问

从仓库右侧的 **Deployments → github-pages** 打开网站。首页是研究图谱，右上角可切换中英文。点击首页「使用说明」里的对读示例，就能看见从 *Bayesian Persuasion* 到 *Competition in Persuasion* 的变化。前一篇讨论一个发送者如何选择实验，后一篇考察多个发送者各自选择实验时的均衡。展开论文卡上的「后作」，就能继续沿另一个方向阅读。[2011 年原文](https://doi.org/10.1257/aer.101.6.2590) · [2017 年后作](https://doi.org/10.1093/restud/rdw052)

| 想做的事 | 去哪里 |
| --- | --- |
| 为读书会梳理一支文献 | 在「研究图谱」搜作者、题名或研究问题。精读关系解释模型变化，引文关系提供引用证据。 |
| 为入门课找讲义和综述 | 在「阅读指南」选分支、作者或读物类型，可进一步筛选免注册的免费版本。 |
| 看近期期刊论文、公开 R&R、美国高校 JMP 或会议论文 | 打开「近期论文」，选栏目，再按主题或方法筛选。点进记录可查看原始来源。 |
| 判断某份名单核到了哪里 | 在「来源与覆盖」看该来源的核查范围、缺口和最近核查日期。 |

## 可以怎样参与

欢迎通过 GitHub Issue 指出重要遗漏、失效链接或需要修正的论文关系。请附上本站条目、DOI 或作者公开页面。若是关系说明，指出相关定理或原文页码尤其有帮助。涉及个人信息、撤链或版权的问题，请直接联系维护者。

网站和数据由 GitHub Pages 提供给读者。每日更新从原公共维护服务获取新快照。部署说明和更新失败时保留上一版的方式见 [首次发布和日常维护](PUBLISH.md)。
