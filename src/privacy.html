隐私说明

这个版本使用 GitHub Pages 提供静态网页。浏览和搜索无需注册。

阅读活动

网站没有访客分析脚本，不向维护者发送论文点击、停留时间、搜索词或阅读轨迹。搜索和筛选在浏览器内完成。

如果复制含有搜索词或筛选条件的网址，收到链接的人可以看到这些条件。

语言偏好

主动切换语言时，网站会在当前浏览器的本地存储中记住你的选择。清除本站的浏览器数据即可删除这项偏好。

托管和外部网站

GitHub 说明，访问 GitHub Pages 时，无论访客是否登录 GitHub，平台都会为安全目的记录并存储访客 IP 地址。

GitHub Pages 的数据收集说明 · GitHub 隐私声明

打开期刊、作者或其他外站的链接后，对方网站将根据自己的隐私政策处理访问请求。

公开记录与更正

书目信息来自公开的学术资料。有关署名、论文状态、版权或撤链的问题，欢迎将条目网址和需要更正之处发给维护者。
